==============================
 사업비 인건비 배분 앱 서버 실행 방법
==============================

[ 접속 주소 ]
  - 프론트엔드 : http://localhost:5173
  - 백엔드 API : http://localhost:8001
  - API 문서    : http://localhost:8001/docs


==============================
 백엔드 실행 (FastAPI + uvicorn)
==============================

1. 터미널에서 백엔드 디렉토리로 이동
   cd D:\AI\business_management\salary-app\backend

2. 서버 실행 (uv 사용)
   uv run uvicorn main:app --host 0.0.0.0 --port 8001 --reload

   * --reload 옵션: 코드 변경 시 자동 재시작
   * 포트 충돌 시 --port 8001 을 다른 번호로 변경

3. 종료
   Ctrl + C


==============================
 프론트엔드 실행 (Vite + React)
==============================

1. 터미널에서 프론트엔드 디렉토리로 이동
   cd D:\AI\business_management\salary-app\frontend

2. (최초 1회) 패키지 설치
   npm install

3. 개발 서버 실행
   npm run dev

4. 종료
   Ctrl + C


==============================
 백그라운드 동시 실행 (bash)
==============================

  cd D:\AI\business_management\salary-app\backend
  uv run uvicorn main:app --host 0.0.0.0 --port 8001 --reload > srv.log 2>&1 &

  cd D:\AI\business_management\salary-app\frontend
  npm run dev > frontend.log 2>&1 &

  * 백엔드 로그 확인: cat salary-app\backend\srv.log
  * 프론트엔드 로그 확인: cat frontend.log


==============================
 기술 스택 참고
==============================

  백엔드
    - Python 3.14+
    - FastAPI, SQLAlchemy, uvicorn
    - 패키지 관리: uv (uv.lock)
    - DB: SQLite (salary.db)

  프론트엔드
    - Node.js (npm)
    - React 19, TypeScript, Vite
    - 프록시: /api/* → http://localhost:8001
