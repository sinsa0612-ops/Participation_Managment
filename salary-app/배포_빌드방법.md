# 설치 마법사(setup.exe) 배포 가이드

이 앱은 **`salary-app-setup-1.0.0.exe` 설치 마법사 하나**로 배포됩니다.
받는 사람은 파이썬·Node 설치 없이 `setup.exe`를 더블클릭 → Next → 완료만 하면 됩니다.

## 빌드 (개발 PC에서 1회)

요구사항: **Node.js**, **uv**(Python 3.12+), **Inno Setup 6**

> Inno Setup이 없으면:  `winget install JRSoftware.InnoSetup`

가장 간단한 방법 — 루트의 배치 파일 실행:

```bat
build.bat
```

이 한 줄이 ① 프론트엔드 빌드 → ② 백엔드+프론트 onedir 빌드(PyInstaller) → ③ 설치 마법사 생성까지 수행합니다.

수동으로 하려면:

```bat
REM 1) 프론트엔드 빌드
cd frontend
npm install
npm run build

REM 2) 폴더형(onedir) 빌드 (프론트 dist 포함)
cd ..\backend
uv sync
uv run pyinstaller salary-app.spec --noconfirm --clean

REM 3) 설치 마법사 생성
cd ..
"%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" installer\salary-app.iss
```

→ 결과물: **`installer\Output\salary-app-setup-1.0.0.exe`** (약 19MB)

## 배포 & 설치 (다른 PC)

1. `salary-app-setup-1.0.0.exe` 를 대상 PC로 전달.
2. 더블클릭 → 설치 마법사 진행(관리자 권한 불필요, 사용자 영역에 설치).
3. 설치 후 **시작 메뉴 / 바탕화면의 "인건비 배분 프로그램"** 으로 실행.
4. 실행하면 검은 콘솔 창이 뜨고 잠시 후 **기본 브라우저가 자동으로 열림** (`http://127.0.0.1:8001`).
5. 종료하려면 그 검은 콘솔 창을 닫으면 됨.

- **데이터 저장 위치:** `%LOCALAPPDATA%\salary-app\salary.db` (사용자별, PC마다 독립, OneDrive 비동기화). **프로그램을 제거(언인스톨)해도 이 데이터는 보존됨.**
- **로그:** `%LOCALAPPDATA%\salary-app\logs\app.log` — 다른 PC에서 문제가 생기면 이 파일을 받아 원인을 확인할 수 있음.
- **첫 실행:** DB가 비어 있음 → 연구원/사업을 추가하거나 CSV 업로드로 시작.
- **포트:** 8001 우선, 사용 중이면 8002~8020 중 빈 포트를 자동으로 사용.
- **방화벽:** 최초 실행 시 안내가 떠도 외부 연결이 아니라 내 PC 안(localhost)에서만 도는 것이므로 허용/무시해도 됨.

## 이전 "단일 exe"에서 바뀐 점 (왜 다른 PC에서 안 됐는지)

- **원인:** 구버전에서 만들어진 DB에 신버전 코드가 없는 컬럼(`projects.sort_order` 등)을 조회 →
  `no such column` 500 오류 → "실행은 되는데 사업/배분 기능이 작동하지 않는" 증상.
- **해결:** 앱 시작 시 **자동 스키마 마이그레이션**(`app/migrations.py`)이 모델과 실제 DB를
  대조해 누락 컬럼/테이블을 자동으로 채운다. 구버전 DB가 있어도 자가 치유됨.
- **패키징 방식:** 실행마다 임시폴더에 압축을 푸는 onefile → **onedir(폴더형)** 로 변경해
  백신 오탐·임시폴더 정책 문제를 줄이고 시작을 빠르게 했으며, 이를 **Inno Setup 설치 마법사**로
  감싸 비개발자도 바로 설치·사용할 수 있게 했다.

## 참고

- **SmartScreen 경고:** 코드 서명이 없는 설치 파일은 처음 실행 시 "Windows가 PC를 보호했습니다"가
  뜰 수 있음 → **추가 정보 → 실행**을 누르면 됨. 정식으로 없애려면 코드 서명 인증서가 필요(별도 비용).
- 버전을 올릴 때는 `installer\salary-app.iss` 의 `MyAppVersion` 과 `build.bat`/이 문서의 파일명을 함께 갱신.
